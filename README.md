# Tully's Coffee 2027 Happy Bag 予約申込フォーム（和光理化学研究所店）

- **フォーム画面**：この リポジトリの `index.html`（GitHub Pages で公開）
- **データの保存先**：Google スプレッドシート「Tully's Coffee 2027 Happy Bag 予約申込（和光理化学研究所店）」の「申込一覧」シート
- **受付処理**：`apps-script/コード.gs`（スプレッドシートに紐づく Apps Script）。在庫チェック、申込番号の発行、確認メールの送信を行います

## 設置手順

### 1. Apps Script をデプロイする
1. スプレッドシートを開き、「拡張機能」→「Apps Script」
2. `コード.gs` の中身をすべて消し、`apps-script/コード.gs` の内容を貼り付けて保存
   （以前 `index` という HTML ファイルを作っていた場合は削除して構いません）
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 権限を許可し、表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）をコピー

### 2. フォームに URL を設定する
`index.html` の次の行の `PASTE_YOUR_APPS_SCRIPT_URL_HERE` を、コピーした URL に置き換えてコミットします。

```js
var API_URL = 'PASTE_YOUR_APPS_SCRIPT_URL_HERE';
```

### 3. 商品画像を置く
`images/` フォルダに `hp2027-5000.jpg` と `hp2027-10000-v2.jpg` をアップロードします（GitHub の画面の「Add file」→「Upload files」で可）。

## 運用メモ
- 受付期間・引取日・注意事項・用意数などは、スプレッドシートの「設定」シートの黄色いセルを書き換えるとフォームに反映されます
- 受け取り・キャンセルは「申込一覧」の「状況」列で切り替えます。キャンセルにすると申込数から外れます
- `コード.gs` を書き換えたときは「デプロイ」→「デプロイを管理」→ 編集 →「新バージョン」で更新します（URL は変わりません）
- 確認メールは店舗の Google アカウントから送られます（無料アカウントは 1 日 100 通まで）
